📋 micro:bit 設定說明
一、在 MakeCode 加入藍牙功能
  1. 開啟 makecode.microbit.org，建立新專案。
  2. 左邊選單捲到最底，選擇「擴展 Extensions」。
  3. 搜尋並加入 bluetooth。
  4. 加入後，「無線電 Radio」類別會被移除，這是正常的，兩者不能同時使用。
二、開啟藍牙服務
  1. 在「當開機時 on start」放入 bluetooth uart service。
  2. 按右上角齒輪 ⚙ → Project Settings。
  3. 將 No Pairing Required: Anyone can connect via Bluetooth 設為開啟。
  4. 這一步是必須的，否則瀏覽器無法連接。
三、接收並解析座標

本網頁傳送的訊號格式如下：

情況傳送內容意思
偵測到足球BALL,72,38X = 72、Y = 38
沒有偵測到NONE畫面中沒有足球

X 由畫面最左的 0 至最右的 100；Y 由最頂的 0 至最底的 100。 畫面正中央即為 50, 50。座標改變時立即傳送，另外每 2 秒重複傳送一次現況。

  1. 使用「當 UART 收到資料（以 新行 分隔）」積木讀取字串。
  2. 用「文字 Text」類別的 split 積木，以 , 分割字串。
  3. 第 0 項是 BALL，第 1 項是 X，第 2 項是 Y。
  4. 用 parse to number 將 X、Y 轉換為數字。
四、判斷方向
X 數值足球位置
小於 40左邊
40 至 60中間
大於 60右邊

若要控制馬達追蹤足球，可直接使用 X − 50 作為誤差值： 負數代表足球偏左，正數代表偏右，數值愈大代表偏離愈遠。 將此誤差值乘以一個係數後輸入馬達速度，即可實現比例控制，轉動會比分段判斷平順得多。

五、連接注意事項
  1. 電腦請使用 Chrome 或 Edge。
  2. iPad 及 iPhone 的 Safari 與 Chrome 均不支援 Web Bluetooth，需要在 App Store 安裝 Bluefy 瀏覽器。
  3. 網頁必須以 https:// 或 localhost 開啟，藍牙與鏡頭才可使用。
  4. micro:bit 需自行供電（電池盒或 USB），並保持在數米範圍內。
  5. 一部 micro:bit 同一時間只能連接一個裝置。
