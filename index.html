📋 使用說明 · iPad 設定 · micro:bit 程式
⚠️ 檔案一定要齊，放喺同一個資料夾：
  1. football-microbit.html
  2. edge-impulse-standalone.js
  3. edge-impulse-standalone.wasm（約 8 MB，第一次載入要等幾秒）
  4. server.py
方法一：GitHub Pages（推薦，有 https，iPad 都用得）
  1. 將成個資料夾上載去一個 public repo。
  2. Settings → Pages → Source 揀 main / (root) → Save。
  3. 等 1～2 分鐘，開 https://你嘅帳戶.github.io/repo名稱/。
  4. GitHub 會自動用啱 .wasm 嘅 MIME type，唔使 server.py。
方法二：本機測試
  1. 喺資料夾開終端機，行 python3 server.py —— 必須用呢個，唔可以用普通 python -m http.server，因為 .wasm 檔要正確嘅 MIME type 先載入到。
  2. 開 http://localhost:8082/。
我嘅 FOMO 模型（football-tracker）：
  1. 輸入 160×160 灰階，標籤 football，屬 constrained object detection（FOMO）。
  2. 影像對齊要同你喺 Edge Impulse 訓練時嘅 Resize mode 一致：訓練揀咗 Squash 就揀「拉伸」，揀咗 Fit shortest axis 就揀「置中裁切」。揀錯會準確度大跌。
  3. 信心門檻調低啲＝易認到但假警報多；調高啲＝準但易漏。由 0.5 開始試。
  4. 框大小：FOMO 只輸出中心點、冇真實尺寸，所以個框係固定大細，用滑桿調到啱你隻波就得。
  5. 認得唔好嘅話可以切返「內置 COCO-SSD」對比。
iPad：
  1. 鏡頭同 AI 偵測：Safari 直接開就用得（要 https 或 localhost）。
  2. 藍牙：iPadOS 嘅 Safari / Chrome 唔支援 Web Bluetooth。要裝 App Store 嘅 Bluefy 瀏覽器（免費版夠用），用佢開呢個網頁，藍牙就連得到 micro:bit。
  3. 網頁要放喺可以上網嘅位置（例如 GitHub Pages、Netlify），或者電腦開 server 後用同一個 Wi-Fi 嘅 IP（如 http://192.168.1.5:8000）——注意非 https 嘅 IP 位址，Safari 唔會俾用鏡頭，所以建議整個 https 網址。
  4. iPad 揀「後鏡」影波最方便，撳「切換鏡頭」轉前後鏡。
micro:bit 準備（MakeCode）：
  1. Extensions 加入 bluetooth。
  2. 「當開機時」放入 bluetooth uart service。
  3. ⚙ Project Settings → 揀 No Pairing Required。
  4. 用「當 UART 收到資料（以 新行 分隔）」讀字串。
訊號格式：見到波 → BALL,x,y（例 BALL,72,38）。X、Y 都係 0～100 嘅百分比座標：X 由左邊 0 至右邊 100，Y 由頂 0 至底 100，畫面正中係 50,50。見唔到波 → NONE。座標一變即傳，另每 2 秒重覆現況。
MakeCode 拆座標：用 Text 類別嘅 split 以 , 分割，第 1 項係 X、第 2 項係 Y，再 parse to number。
判斷方向：X < 40 = 左，40～60 = 中，X > 60 = 右。想控制摩打追波，可以直接用 X - 50 做誤差值（負數即係波喺左邊，正數即係右邊），數值越大代表偏得越遠，好啱用嚟做比例控制。
