訊號記錄

📋 使用說明 & micro:bit 設定
網頁點樣開：
  1. 要用 Chrome / Edge（Web Bluetooth 只支援呢啲瀏覽器）。
  2. 鏡頭同藍牙都要 https:// 或者 localhost 先用得。最簡單：喺檔案所在資料夾開終端機，行 python -m http.server 8000，然後開 http://localhost:8000/football-microbit.html。
micro:bit 要準備：
  1. 去 MakeCode，新增擴展（Extensions）→ 搜尋 bluetooth 加入。
  2. 喺「當開機時 on start」放入 bluetooth uart service（藍牙 UART 服務）。
  3. 齒輪 ⚙ → Project Settings → 揀 No Pairing Required（JustWorks）。
  4. 用「當 UART 收到資料（以換行分隔）」讀字串：收到 BALL 顯示 ⚽ 圖案，收到 NONE 就清空螢幕。
網頁會傳送嘅訊號：見到足球 → BALL,x,y（例如 BALL,3,2 即係 X 第 3 格、Y 第 2 格；X 由左至右 1~5，Y 由上至下 1~4）；足球消失 → NONE。每次位置改變傳一次，另外每 2 秒重覆一次現況。
MakeCode 拆解座標：用「文字 Text」類別入面嘅 split（分割字串）積木，以 , 分割收到嘅字串，第 0 項係 BALL，第 1 項係 X，第 2 項係 Y，再用 parse to number 轉做數字。想判斷左右：X ≤ 2 係左邊，X ≥ 4 係右邊，X = 3 係中間。
